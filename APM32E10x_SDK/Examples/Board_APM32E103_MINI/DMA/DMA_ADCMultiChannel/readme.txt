&par Example Description

This example provides an example of how to use a DMA channel to transfer
continuously a data from a peripheral (ADC1) to DMA transfer. The ADC channel0-3
for APMF103 MINI Board is configured to be converted when device startup.
The value of ADC is shown in USART1.

using ADC Channel0-3 (PA0-3)

The USART1 is configured as follows:
    - TX:PA9, RX:PA10
    - BaudRate = 115200 baud
    - Word Length = 8 Bits
    - One Stop Bit
    - No parity
    - Hardware flow control disabled (RTS and CTS signals)
    - Receive and transmit enabled

&par Directory contents

  - DMA/ADC_MULTI_CHANNEL/src/apm32f10x_int.c		Interrupt handlers
  - DMA/ADC_MULTI_CHANNEL/src/main.c				Main program

&par IDE environment

  - MDK-ARM V5.29
  - EWARM V8.50.4.26131
  - ECLIPSE-EMB V4.24.0

&par Hardware and Software environment

  - This example runs on APM32F103_MINI Devices.
